# Kjemilab 1.1

Added Periodesystemet with a searchable first-20 table, visible group/period patterns, selected-element shell details, editable practice selection, 210 new questions and 12 authored oral practice prompts. The first-20 range is a chosen practice subset, not a teacher-imposed memorization list.

Added adaptive, bounded repetition and separate later-recall evidence. Answers remain hidden before a successful attempt or an explicit reveal. Hints, lookups and retries do not count as independent first answers. Oral checklists are manual self-assessment, not machine grading.

Added optional backward-compatible progress, validated imports, stored notes and participant rotation. Added source F6 for the project assignment and explicit authorship/scope notes. Preserved the existing course, 120 questions, teacher worksheet tasks, 12 molecule targets and four laboratories.

Fixed custom selection collapse, sparse rubric serialization, stale note updates after source dialogs and loss of horizontal table position on mobile interaction. New and original regression suites pass under the documented Chromium rendering method. See VERIFICATION.md for exact coverage and browser limitations.
